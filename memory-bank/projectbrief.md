# Project Brief — Aerial Championship (Turkey)

## Core Idea
Одностраничный промо-сайт международного чемпионата по воздушным видам спорта
(aerial silk / hoop) на Турецкой Ривьере. Контент на английском, комментарии в коде — на русском.

## Requirements
- Единственный файл: `index.html` (HTML + inline CSS + inline vanilla JS). Сборки нет.
- Изображения лежат локально в корне проекта (JPG/AVIF, Unsplash-происхождение).
- Секции: hero (анимированный заголовок, счётчики 25+ стран / €15,000 / 12 m, hero-визуал),
  About, дисциплины (карточки), расписание, билеты, футер (структура уточняется по коду).
- Анимации: kenburns hero, reveal-on-scroll, счётчики с IntersectionObserver, параллакс heroVisual.

## Source of Truth
Всё решение принимается по содержимому `index.html` — других исходников нет.
